# Security policy

## Supported versions

Only the latest Velo release receives security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting when available. Otherwise, contact the maintainer privately before opening a public issue.

Include the affected version, steps to reproduce, impact, and any files needed to show the problem. Do not post authentication tokens, full settings backups, or personal data publicly. **Settings → About & Support → Copy diagnostics** provides a safe system summary.

Other bugs: <https://github.com/aechXIII/Velo/issues>
